# 4WINGMEN Interactive Brand Book — Asset Guidelines

**Status:** Asset inventory and production requirements.

## 1. Source-of-truth rule
Use assets supplied or explicitly approved by the 4WINGMEN team. Do not substitute generated or stock portraits for the four actual team members. Do not alter identity-defining facial features. Keep source files unchanged and create separate derivatives for web use.

## 2. Current known assets
- Official 4WINGMEN logo: user supplied a square PNG showing the black logo on a white circular field.
- Team portraits: four editorial photographs were supplied in the conversation:
  - Aryan Singh — black editorial portrait with arms crossed.
  - Saad Gani — monochrome boxing portrait.
  - Ayush — formal black suit portrait with red typography in the supplied composition.
  - Zaid Ahmad — dark streetwear portrait with sunglasses.

The supplied portraits are visual references; obtain original high-resolution image files before production if available.

## 3. Logo handling
- Preserve original geometry, proportions and lettering.
- Do not redraw, replace or distort the mark.
- Inspect the supplied PNG to determine whether the surrounding black area and white circle are actual pixels or transparency.
- Keep the original asset in the repository unchanged.
- Create transparent or reversed variants only through faithful image preparation and review.
- Do not use an approximate font to recreate the wordmark.

## 4. Team photography
For each member, request:
- Original high-resolution photograph.
- Permission/approval for website publication and image treatment.
- Preferred name spelling and display name.
- Approved role/title and short biography.
- Optional additional portrait or action photograph.

Image treatment may include crop, tonal adjustment, background separation and monochrome conversion, subject to approval. Do not imply that the reference images are higher resolution than the supplied files.

## 5. Portfolio assets
For every selected project, request:
- Project name and client/brand name (if publishable).
- Project description and 4WINGMEN's contribution.
- Approved screenshots, photographs or video.
- Publication permission and credits.
- Verifiable results only, with source and timeframe if metrics are used.

Do not invent project details or performance results.

## 6. File formats and optimisation
Recommended:
- SVG for clean vector logos and simple graphics when available.
- WebP or AVIF for photographic derivatives.
- PNG for transparency when required.
- WOFF2 for licensed web fonts.
- MP4/WebM only for approved motion assets.

Use descriptive, lowercase, hyphenated filenames. Keep originals separate from optimised exports. Generate responsive image sizes rather than serving one oversized image to every device.

## 7. Suggested asset folders

public/
- brand/ — original logo and approved variants
- team/ — per-member original and web derivatives
- projects/ — approved portfolio media
- textures/ — graphics and texture assets
- fonts/ — licensed web fonts

The logo SVG filenames sometimes proposed for this project are placeholders for future approved exports, not existing files.

- Licensed font files or chosen font families.
