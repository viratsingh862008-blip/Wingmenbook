**Status:** Original assets received, visually verified, mapped and hosted.

## 1. Source-of-truth rule
Use assets supplied or explicitly approved by the 4WINGMEN team. Do not substitute generated or stock portraits for the four actual team members. Do not alter identity-defining facial features. Keep the supplied files unchanged; create separate derivatives only when required for performance and review those derivatives before use.

- Use the supplied official PNG unchanged.
- Preserve geometry, proportions, lettering and the existing white circular field.
- Do not redraw, replace, stretch, recolour or add effects that change the mark.
- Do not recreate the wordmark with a substitute font.
- The original file is hosted at:
  `https://res.cloudinary.com/roq8nakt/image/upload/v1794639104/4wingmen/brand-book/4wingmen-logo.png`

## 4. Team poster handling
The four supplied team images are complete editorial poster compositions rather than clean isolated headshots. They include embedded names, typography and colour treatment.

- Use the correct mapped source for each team member.
- Display with `object-fit: contain` so the entire artwork remains visible.
- Do not crop away the embedded name or poster typography.
- Do not apply a grayscale filter or automatic background removal to the hosted source.
- Keep the original individual accents: neutral monochrome for Aryan, gold for Saad, red for Ayush and orange for Zaid.
- Use descriptive alt text identifying the team member and that the image is their original poster composition.
- If a hosted image fails, show an explicit unavailable state rather than silently hiding the image.

## 5. Portfolio assets
For every selected project, request:
- Project name and client/brand name (if publishable).
- Project description and the individual's contribution.
- Approved screenshots, photographs or video.
- Publication permission and credits.
- Verifiable results only, with source and timeframe if metrics are used.

Do not invent project details or performance results. Do not present a member's prior work as an official 4WINGMEN agency project unless that attribution is confirmed.

## 6. Formats and optimisation
Recommended:
- SVG for separately approved vector logos and simple graphics.
- WebP or AVIF derivatives for photographs, only after visual fidelity review.
- PNG when transparency or the approved logo source requires it.
- WOFF2 for licensed self-hosted fonts.
- MP4/WebM only for approved motion assets.

Keep originals separate from optimised exports. Generate responsive image sizes rather than serving one oversized image to every device.

## 7. Remaining optional assets
- Separate vector/transparent logo master, if the agency has one.
- Approved high-resolution portrait source files, if different from the supplied poster compositions.
- Approved portfolio images and video with attribution and publication permissions.
- Any sound asset, before sound control is added.
