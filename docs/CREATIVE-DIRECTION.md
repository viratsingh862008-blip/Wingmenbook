# 4WINGMEN Interactive Brand Book — Creative Direction

**Status:** Direction approved; detailed design system pending content and asset review.

## 1. Creative concept
**Contemporary Creative Agency × Luxury Editorial × Interactive Digital Publication**

The book should feel like a carefully art-directed independent publication: confident, image-led, typographically expressive, and immersive. It should not resemble a generic corporate slide deck.

## 2. Approved identity direction
- Primary visual foundation: black and white.
- Signature accent: red.
- Photography: use the supplied real team portraits as the source of truth.
- Official brand mark: use the user-provided 4WINGMEN logo without redrawing, distorting, or substituting it.
- Composition: editorial asymmetry, strong negative space, oversized type, deliberate image crops and layered graphic forms.
- Tone: confident, contemporary, creative and clear.

Exact red/black/white values, typefaces, scale, spacing and motion timings are to be selected during the design-system stage. Do not infer final tokens from screenshots alone.

## 3. Art direction principles
1. **People first:** the four team members should be recognisable and represented accurately.
2. **Editorial hierarchy:** one dominant message per screen; supporting copy remains readable.
3. **Controlled accent:** red should emphasise selected words, chapter markers and graphic moments, not overwhelm every page.
4. **Photographic consistency:** prepare crops, contrast and monochrome treatments as a coherent family while preserving the original photographs.
5. **Motion with purpose:** movement should guide attention, establish depth or communicate a transition.
6. **Responsive composition:** mobile screens must be art-directed independently rather than treated as compressed desktop layouts.

## 4. Logo handling
The supplied logo image is the official reference asset. Preserve its proportions and internal geometry. Do not recreate the feather or lettering using substitute fonts. Prepare derived display variants only from the supplied source, and retain the original file unchanged.

Potential asset variants, subject to preparation:
- Original black mark on its supplied light field.
- Clean transparent dark-background variant, if it can be extracted faithfully.
- Light mark for dark backgrounds, only if a faithful approved source or carefully prepared derivative is available.

Do not assume the current circular white field is transparent. Inspect the image before preparing variants.

## 5. Photography and image treatment
- Use the four user-supplied portraits for the team profiles.
- Do not replace team members with generated or stock people.
- Do not alter identity-defining facial features.
- Create separate crops or cutouts only where the source photograph supports them.
- Keep originals untouched; store optimised derivatives separately.
- Request higher-resolution originals if the supplied versions are insufficient for full-screen use.

## 6. Editorial typography
Use a restrained type system with:
- A display face for oversized names and chapter titles.
- A highly legible sans-serif for body copy and interface labels.
- Optional editorial serif use only where it supports the brand rather than competing with the logo.

Font selection and licensing must be verified before production. The logo lettering must not be approximated with a typeface.

## 7. Reference use
Reference: https://howtotalktowhitekidsaboutracism.com/

Study the reference for interaction qualities such as canvas-based visuals, layered parallax, page movement, navigation and motion choreography. Recreate the desired experience with original 4WINGMEN layouts, assets, content and code. Do not copy the reference's written content, artwork, source code or identity.

## 8. Design approval gates
Before full implementation, approve:
1. One cover composition.
2. One team profile composition.
3. One services composition.
4. The red/black/white token set and typography.
5. A motion test showing the agreed interaction direction.

These approvals become the visual baseline for the remaining chapters.
