# 4WINGMEN Interactive Brand Book

An editorial, chapter-based digital brand book built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run build
```

## Experience

- Guided reading and direct chapter navigation
- Keyboard left/right navigation and touch-friendly controls
- Cinematic monochrome design with member-specific gold, red and orange accents
- Optional sound control (starts muted)
- Responsive layouts and reduced-motion support
- Instagram contact CTA
